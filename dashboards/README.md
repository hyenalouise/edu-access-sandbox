# Dashboards

Exported Databricks AI/BI dashboards (`.lvdash.json`), deployed through `databricks.yml` (`resources.dashboards`).

| File | What it is |
|---|---|
| [`reached_planner.lvdash.json`](reached_planner.lvdash.json) | The ReachED LGU planner for LGU planners and Local School Boards. Generated by [`src/dashboard/planner.py`](../src/dashboard/planner.py); do not edit the JSON by hand |

Regenerate after changing the generator, then run the tests (`tests/test_dashboard.py` fails if the two differ):

```bash
python -m src.dashboard.planner
python -m pytest tests/test_dashboard.py tests/test_local_job.py -q
```

## The four views

A planner moves from many places, to one place, to its schools, then checks how far to trust the result, and takes the downloaded lists to the Schools Division Office and the board meeting.

| View | Question | Main content |
|---|---|---|
| **Overview** | Which cities and municipalities should be reviewed first? | Priority map, what drives each tier, how far high places are above the typical place, the ranked priority list |
| **LGU Profile** | Why is this place a priority, and where should the board look? | The place and its tier, what stands out, why this tier, how reliable the result is, teachers by level and funding, enrollment and school-age population (context only), barangay access, the first schools to follow up |
| **School Action** | Which schools should we check, and why? | The selected school, its place among schools in the same LGU, its enrollment, rooms and teachers, the exact figures to verify, the school action list |
| **Data and Method** | Can we rely on these results, and how were they produced? | How the priority is determined, the typical place of each type, coverage and reasons for data review, whether the Critical list holds under D-057's checks, overlap of measures, source years and data quality checks, limits |

The tier is D-057 from [`lgu_priority_matrix`](../etl/06_analytics/README.md): AP1 to AP3 at or above the 90th percentile within LGU type, after the 90% coverage gate, counted into Critical, Elevated, Targeted, Monitor or Data review. Relative pressure (the LGU's ratio over the median of its type) and D-057's checks come from `lgu_priority_checks`, and the outlier fences from `lgu_priority_outlier_schools`. The dashboard filters, labels and arranges these values; it computes no tier.

## KPIs

| View | KPI | Definition |
|---|---|---|
| Overview | Priority LGUs | Critical plus Elevated: high on at least two of the three measures |
| | Public learners in priority LGUs | SY 2023-24 public-school learners (`affected_learners`) in Critical and Elevated places, with their share of the places in view |
| | Critical LGUs | High on all three measures |
| | LGUs needing data review | Not given a tier because a measure is below the coverage gate |
| LGU Profile | High-pressure measures | Measures at or above the 90th percentile, of 3 |
| | Public learners | `affected_learners`, SY 2023-24 |
| | Barangays without a matched public elementary school | Regular PSGC barangays with no matched active public school offering elementary, of all regular barangays (an upper bound when schools are not matched to a barangay) |
| | Schools with figures to verify | Public schools above an AP2 or AP3 outlier fence, missing a report, or reporting zero rooms or teachers |
| School Action | Learners per reported instructional room | The selected school, all levels, SY 2023-24 |
| | Learners per teacher | At the education level chosen, or all levels |
| | Enrollment change | SY 2020-21 to SY 2025-26, only when both years are complete |
| | Temporary and makeshift rooms | Temporary learning spaces plus makeshift rooms, SY 2023-24 |
| Data and Method | Assessed LGUs | Every measure at 90% coverage or more |
| | LGUs requiring data review | At least one measure below the gate |
| | Stable priority results | Critical within type and nationally, of all Critical |
| | Tier changes without flagged schools | `outliers_change_tier` from `lgu_priority_checks` |

## Filters

Every filter is a query parameter applied after the stored percentiles and tiers are read, so a filter only narrows what is shown.

| Filter | Where it applies |
|---|---|
| Region, Province, LGU type (global) | Every view. Province options follow Region. National checks on Data and Method (the Critical list, the check heatmap, overlap and the typical place) follow LGU type only, and say so |
| City or municipality (global) | LGU Profile and School Action. Defaults to the top place in the filters; a choice outside them falls back to that place and says so |
| Barangay (global) | The barangay and school sections of LGU Profile, and School Action |
| Priority tier, Coverage status (Overview) | The KPIs, map, drivers and priority list. Not the relative-pressure chart, which always compares high places with the rest |
| Education level, School (School Action) | Every School Action visual. School defaults to the first school to check |
| School status (School Action) | The school action list only |
| Measure, Validation check (Data and Method) | Measure: coverage and reasons. Validation check: the published-tier-against-check heatmap |

Databricks dashboards cannot open another page from a click, so a planner picks the place once in *City or municipality*; it stays selected on LGU Profile and School Action.

## What stands out

The LGU Profile's insights are fixed SQL rules over the same tables as its charts, at most four, each left out when its data is incomplete: the strongest measure with its percentile and relative pressure, the data review reason or the outlier check, the enrollment trend when every year is complete (context only), barangays without a matched public elementary school, and locally funded teachers. No generative AI is used, and no sentence states a cause.

## Limits

The dashboard cannot tell how many schools, classrooms or teachers to add, why a place is under pressure, how far learners travel, or whether a reported value is correct. Classroom and teacher figures exist only for SY 2023-24. School-level ratios and flags in School Action are a screening view for follow-up, not the LGU priority rule.
