# `deped_facilities_clean`: Silver data dictionary

Generated by `python -m src.silver.cli dictionary --source deped_facilities` from [the Bronze contract](../../../config/ingestion/deped_facilities.json) and [the Silver mapping](../../../config/mappings/deped_facilities.json). Do not edit by hand; `tests/test_silver.py` fails if it differs.

`` edu_access.`03-silver`.deped_facilities_clean ``: one row per school per school year, for the current delivery of each school year only (`01-control`.current_batches). Key: (`school_id`, `school_year`). Every school in the file is kept, public or not; facility measures exist for public schools only. Location is not here: join `deped_enrollment_clean` on (`school_id`, `school_year`); the gate checks every school is there. Every row names the Bronze row it came from (`source_sha256`, `source_row_number`). Rules, counts, and the gate: [docs/operations/silver.md](../../operations/silver.md#deped-facilities).

**NULL** never means zero. A blank count for a level the school does not offer means not applicable; a blank elementary classroom count at a public school offering elementary is flagged `es_classrooms_missing`.

## Quarantine: `deped_facilities_quarantine`

One row per Bronze row set aside, never deleted: `school_year`, `school_id` as published, `quarantine_reasons` (every reason that applies), and the lineage and run columns above.

- `school_id_blank`: `school_id` is NULL or blank
- `school_id_malformed`: `school_id` is not exactly six digits
- `school_id_duplicated`: the same `school_id` appears more than once in the school year; every copy is set aside
- `count_negative`: a count is a negative whole number
- `count_uncastable`: a count is not blank and not a whole number of at most nine digits (e.g. `5.0`, `abc`)
- `count_above_plausible_max`: a count is above its group's reviewed plausible maximum, e.g. a count with an extra digit
