# `psa_school_age_population_clean`: Silver data dictionary

Generated by `python -m src.silver.cli dictionary --source psa_school_age_population` from [the Bronze contract](../../../config/ingestion/psa_school_age_population.json) and [the Silver rules](../../../config/mappings/psa_school_age_population.json). Do not edit by hand; `tests/test_silver_school_age.py` fails if it differs.

`` edu_access.`03-silver`.psa_school_age_population_clean ``: one row per count cell of the current census workbooks (`01-control`.current_batches): census year, population concept, place, sex and single-year age 5-24. Key: (`census_year`, `population_concept`, `place_name`, `parent_name`, `sex`, `age`). Every row names the Bronze row it came from (`source_sha256`, `source_sheet`, `source_row_number`), so each count can be read back from Bronze. Rules, counts and the gate: [docs/operations/silver.md](../../operations/silver.md#psa-school-age-population).

**Places are names only**, as published: no PSGC code. Their level and parent come from the sums, because the workbooks have neither (profile O-2). Matching the names to PSGC 2Q 2026 is the Integration map's job (`05_map_psa_school_age_population_psgc`), with the shared matching rules and reviewed aliases.

**Never mix the two concepts** in one ratio: `total` is everyone, `household` leaves out people in institutional living quarters (D-029). AP4 uses `total`, both sexes, ages 5-17 (D-042). Every level is in the table, so filter `level` before summing: the country, regions and provinces are sums of the places below them.

**Levels per workbook**, pinned in the Silver rules and checked by the gate: 2020: country 1, region 17, province 82, city municipality 1,642; 2024: country 1, region 18, province 83, city municipality 1,642. `level` is the place's position in the tree, not a verified PSGC level: `place_status` marks the places at a province or city position that are not a PSGC province or LGU (the Special Geographic Area and its 2020 clusters), for the Integration map (#159) to set aside.

## `psa_school_age_population_quarantine`

Cells whose count cannot be typed, set aside rather than deleted. Every count cell of a current batch is in exactly one of the two tables. Any quarantined cell fails the gate, so a published build has none: the profile found every count complete (O-3).

| `logical_dataset` | STRING | The approved dataset the delivery belongs to (D-018): `school_age_population_2020` or `school_age_population_2024` |

## Not in Silver

- Title, header, note and source rows: they stay in Bronze (`source_row_kind`).
- No PSGC code, no 2023 estimate, no age-group totals: Integration and Gold choices (#158).
- No row for a place the workbook does not list.
