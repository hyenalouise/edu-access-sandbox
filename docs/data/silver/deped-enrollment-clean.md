# `deped_enrollment_clean`: Silver data dictionary

Generated by `python -m src.silver.cli dictionary --source deped_enrollment` from [the Bronze contract](../../../config/ingestion/deped_enrollment.json) and [the Silver mapping](../../../config/mappings/deped_enrollment.json). Do not edit by hand; `tests/test_silver.py` fails if it differs.

`` edu_access.`03-silver`.deped_enrollment_clean ``: one row per school per school year, for the current delivery of each school year only (`01-control`.current_batches). Key: (`school_id`, `school_year`). Grade, sex, and strand stay as columns (the publisher's wide shape); unpivoting is a Gold decision. Every row names the Bronze row it came from (`source_sha256`, `source_row_number`), so the published value of any column can be read back from Bronze. Rules, counts, and the gate: [docs/operations/silver.md](../../operations/silver.md).

**NULL** never means zero. A count column that a school year's file does not have is NULL too; `schema_version` tells the two apart (`v1` lacks `modified_curricular_offering_classification`, `g11_sshs_acad_male`, `g11_sshs_acad_female`, `g11_sshs_techpro_male`, `g11_sshs_techpro_female`).

## `deped_enrollment_quarantine`

Rows that cannot be trusted, set aside rather than deleted. Every current Bronze row is in exactly one of the two tables. Read the published values from Bronze with `source_sha256` and `source_row_number`.

| Column | Type | Meaning |
|---|---|---|
| `school_year` | STRING | As in the clean table |
| `school_id` | STRING | As published, even if blank or malformed |
| `quarantine_reasons` | `ARRAY<STRING>` | Every reason that applies, never empty (below) |
| `batch_id` | STRING | The Bronze batch (one delivery of one school year) the row came from; joins `01-control`.ingestion_batches |
| `delivery_version` | INT | Which delivery of the school year: 1, or 2+ after a publisher revision |
| `schema_version` | STRING | Which header the file had; tells a column absent that year (NULL) from a published blank (NULL) |
| `source_sha256` | STRING | SHA-256 of the publisher's CSV; with `source_row_number`, identifies the Bronze row exactly |
| `source_row_number` | BIGINT | The row's position in that CSV (data rows from 1) |
| `run_id` | STRING | The job run that built the row (`{{job.run_id}}`); every row of a build has the same one, as do the gate's results |
| `cleaned_at_utc` | TIMESTAMP | When that build ran; one value for both tables, in UTC |
| `code_revision` | STRING | The commit that ran the build |

| Reason | Meaning |
|---|---|
| `school_id_blank` | `school_id` is NULL or blank |
| `school_id_malformed` | `school_id` is not exactly six digits |
| `school_id_duplicated` | the same `school_id` appears more than once in the school year; every copy is set aside |
| `count_negative` | a count is a negative whole number |
| `count_uncastable` | a count is not blank and not a whole number of at most nine digits (e.g. `5.0`, `abc`) |
| `count_above_plausible_max` | a count is above the reviewed plausible maximum (10,000), e.g. a count with an extra digit |
