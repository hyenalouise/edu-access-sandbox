## How to rerun

```bash
RAW_DATA_DIR=~/Projects/reached-hq/raw-data python analysis/profiling/profile_deped.py
```

`RAW_DATA_DIR` must contain `deped/original/` with the zips listed in the script, including `Enrollment-in-SY-2020-2021.zip`, `Enrollment-in-SY-2021-2022.zip`, and `Enrollment-in-SY-2022-2023.zip` (download each from `https://www.deped.gov.ph/wp-content/uploads/<file name>`). The script stops if any of them is missing, and `analysis/profiling/dictionary_deped.py` needs the same zips. Every result prints under its finding ID below.

## Summary

Clean and usable at school level: `school_id` is a reliable key within each year, and every enrollment count is a valid whole number. The main work before analysis is matching place names to PSGC and harmonizing SY 2025-26, which changed encoding, columns, and category labels. SY 2020-21, 2021-22, and 2022-23 have the same layout, labels, and README as SY 2023-24 and load the same way. What differs is their content: the DepEd region label of 192 schools in Cotabato City and North Cotabato changes from Region XII to BARMM in SY 2021-22; `Local Government` management appears only in SY 2020-21 to 2022-23; SY 2020-21 has more private schools with no learners; and SY 2022-23 has one seven-digit school ID with 8 Kindergarten learners whose school name also appears under a six-digit ID (O-1).

## Changes across files or years

- SY 2020-21 to 2024-25: identical columns and column order (78 columns), and the same `README.md`.
- SY 2021-22: the first year with the Cotabato City and North Cotabato schools labeled BARMM (O-10).
- SY 2020-21 to 2022-23: the only years with `Local Government` management (O-8).
- SY 2025-26: 83 columns, Windows-1252 encoding, CRLF line endings, relabeled categories (O-6 to O-8).
