## How to rerun

```bash
RAW_DATA_DIR=~/Projects/reached-hq/raw-data python analysis/profiling/profile_deped_enrollment_psgc.py
```

The workbook must be at `$RAW_DATA_DIR/deped/original/`. The cross-checks are optional: X-1 runs if `deped/original/Enrollment-in-SY-2023-2024.zip` is present with the SHA-256 on the [deped_enrollment card](../deped_enrollment/README.md#files); X-2 runs if `psa/original/` holds the two PSGC files with the SHA-256 on the [psa_psgc card](../psa_psgc/README.md); the S-3 year check and X-4 run per year if the SY 2024-25 and 2025-26 enrollment zips are in `deped/original/` with the SHA-256 on the deped_enrollment card; X-3 runs the team's name matching ([`cross_source_deped.py`](../../../../analysis/cross_source/cross_source_deped.py)), so it needs that script's five DepEd zips in `deped/original/` too, and rewrites its generated list unchanged. Otherwise each prints `skipped`. Each finding below prints under its ID. The column statistics in [data_dictionary.md](data_dictionary.md) come from `analysis/profiling/dictionary_deped_enrollment_psgc.py`. Two runs on the same files give identical output.

## Summary

The SY 2023-24 school enrollment that the team already has (deped_enrollment), plus a PSGC code for each school's barangay and the school's coordinates. Enrollment is identical to deped_enrollment for all 60,167 shared schools (X-1), so this source adds **location, not counts**. The PSGC codes are the main gain: 59,500 schools (98.7%) have a barangay code that PSA knows (X-2). Before joining, codes must be padded to 10 digits (O-5), and Sulu's 467 codes need their province prefix updated to 2Q 2026 (X-2). Against the team's name matching, the codes agree for 46,652 public schools and follow the current boundaries for 170 that name matching places in an old municipality, mostly the 2024 Special Geographic Area towns and EMBO (X-3). The coordinates are weak: 23% are missing and at least 2,275 schools are placed over 100 km from their own city or municipality (O-10, O-11). Use them for maps only after a boundary check (S-1), not for distance measures.
